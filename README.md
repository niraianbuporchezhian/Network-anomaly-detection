# Network-anomaly-detection
Python-based network anomaly detection system using KNN machine learning and rule-based techniques to identify anomalous data, suspicious URLs, and known malicious IP addresses.
Network Anomaly Detection

A Python-based network security project that combines machine learning and rule-based detection techniques. The project uses the PyOD KNN algorithm to identify anomalous data points and visualize the learned anomaly decision boundary. It also includes rule-based checks for potentially phishing URLs and known malicious IP addresses.

Key components:

KNN-based anomaly detection using PyOD
Synthetic training data generation with inliers and outliers
Anomaly scoring and prediction
Visualization of anomaly decision boundaries using Matplotlib
Rule-based phishing URL detection using regular expressions
Known malicious IP detection using a predefined IP list
Prediction-error calculation for the anomaly detection model

Technologies: Python, NumPy, SciPy, PyOD, Scikit-learn-compatible anomaly detection, Matplotlib, Regular Expressions
